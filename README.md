
# Event Admin Panel

A responsive MERN Stack application for managing events.

## Features
- View events and registration counts
- Add, update and delete events
- Responsive dashboard

## Technologies
- React, Vite, Axios, React Router
- Node.js, Express.js
- MongoDB Atlas, Mongoose

## Run the Project

### Backend
Run these commands inside `backend`:

```bash
npm install
npm start
```

Configure `backend/.env` with a valid MongoDB Atlas URI before starting.

### Frontend
Run these commands inside `frontend`:

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

Never publish real database passwords or secrets in a public repository.
